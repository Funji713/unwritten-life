# 未定人生 · 公開試玩入口

這個儲存庫只放靜態入口。遊戲與存檔由目前的試玩主機提供，GitHub Pages 不執行遊戲後端。

網址：https://funji713.github.io/unwritten-life/

主機需要保持開機、喚醒及網路連線。AI 服務須由主機擁有者手動開啟；入口不會替主機啟動 AI。TEST 點皆為模擬，沒有真實付款。

試玩主機網址改變時，更新 `index.html` 內唯一的 `id="start-game"` 連結並重新發布。原專案可執行 `node scripts/update-github-entry.mjs`，從經驗證的公開主機設定更新此靜態檔，再上傳本目錄三個檔案。固定入口不會自動得知暫時主機的新網址。

請定期在遊戲中匯出人物備份。換網域後瀏覽器憑證不會自動轉移，需匯入人物；TEST 錢包不匯入。
